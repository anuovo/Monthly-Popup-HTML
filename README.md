# Monthly Popup HTML

Static HTML prototype for the monthly popup workflow.

## Files
- `index.html` — primary prototype with two implementation variants:
  - Variant A: Counter Offer
  - Variant B: Award

## Purpose
This file is intended for product/design review and developer handoff. It is a front-end mockup only and does not include functional business logic.

## Notes for Developers
- Built as a single self-contained HTML file with embedded CSS
- Designed to make layout states easy to compare
- Can be split into reusable components during implementation
